# 涉法危机预案与多场景推演

## 概述表格
| 项目 | 内容 |
|------|------|
| **能力名称** | 涉法危机预案与多场景推演 (Legal Crisis Simulation & Contingency Planning) |
| **核心目标** | 识别法定权利行使窗口期，构建多分支博弈决策树，制定黄金应急行动排期与合规沟通预案 |
| **输入** | 执法通知书、查封裁定、涉案事实简报、突发舆情/泄露报告、初步调查记录等非结构化文本 |
| **输出** | ① 危机定性与法定应对窗口期倒计时表；② 乐观/基准/悲观三阶情景决策树；③ 黄金 24h/72h/7d 应急行动排期；④ 对外声明与沟通口径法律红线指引 |
| **前置技能** | `legal-element-extraction`（要素提取）、`legal-norm-validity-check`（法规效力审查） |
| **后续技能** | `argument-chain-construction`（申辩/抗辩论证构建）、`case-lifecycle-planning`（诉讼全周期规划） |
| **风险等级** | **极高** — 错过法定申辩/听证时限或盲目对外表态，将直接导致不可逆的行政处罚加重或自认败诉 |
| **适用法域** | 中华人民共和国法律体系（行政处罚法、民事诉讼法、刑事诉讼法、网络安全法、反不正当竞争法等） |

## 法律声明
> **重要提示：** 涉法危机应对涉及重大人身自由、财产处置与行政强制措施，本技能输出的推演方案仅供法务团队与危机应对小组决策参考。
> 1. 遇到公安机关刑事侦查或行政机关突击现场执法，应立即聘请执业律师到场处理；
> 2. 严禁实施任何销毁证据、隐匿账簿、指使证人作伪证、串供等违法犯罪行为；
> 3. 所有对外公开发布的声明、律师函及致客户函，必须经执业律师与公关团队双重合规审查后方可对外发布。

## 一、理论依据与认知模型

法律危机具有**突发性、高对抗性、时间窗口极短、多主体利益交织**等特征。本技能融合了现代法学与危机管理理论：

1. **危机管理 4R 理论 (Reduction 缩减 / Readiness 预备 / Response 反应 / Recovery 恢复)：** 重点聚焦“Response（快速反应）”阶段，以小时为单位建立阻断损失扩大的行动链路。
2. **博弈论与决策树分析 (Decision Tree & Game Theory)：** 针对执法机关、相对方、公众媒体及司法裁判者可能采取的行动，反向推演不同策略（主动自首自查 / 申请听证抗辩 / 和解整改）的期望收益与风险概率。
3. **行政裁量基准与从轻减轻法定要件理论：** 严格对照《行政处罚法》第32条（从轻减轻）与第33条（首违不罚/不予处罚）法定要件，在黄金窗口期内系统搜集并固定从宽情节证据。

## 二、标准执行工作流程

### 步骤 1：危机定性与法定应对窗口期识别
1. **法律责任多维定性：** 判定属于民事侵权/违约、行政违法、治安处罚还是刑事涉案，是否存在“行刑交叉”（如涉税案由行政稽查转公安经侦）；
2. **锁定核心法定时间节点（倒计时）：**
   - **行政处罚听证申请期：** 收到事先告知书之日起 **5 个工作日内**；
   - **行政处罚陈述申辩期：** 收到事先告知书之日起 **5 个工作日内**（部分法规规定 3 个工作日）；
   - **行政复议申请期：** 知道行政决定之日起 **60 日内**；
   - **保全异议提出期：** 收到查封保全裁定之日起 **5 日内**；
   - **网络安全事件上报期：** 发生重大数据安全事件 **2 小时内** 向监管部门初报。

### 步骤 2：三阶情景决策树推演 (Multi-Scenario Simulation)
针对危机走向进行全景化推演：

```
                    ┌── 🟢 乐观情景 (Best-Case) ─────────────┐
                    │  条件: 认定不予处罚/首违不罚/达成和解   │
                    │  后果: 责令整改，免除罚款，保全解除    │
                    │                                        │
[ 决策触发点 ] ─────┼── 🟡 基准情景 (Base-Case) ─────────────┤
                    │  条件: 认定从轻减轻，积极消除危害后果  │
                    │  后果: 处以法定幅度下限罚款，暂停曝光  │
                    │                                        │
                    └── 🔴 悲观情景 (Worst-Case) ────────────┘
                       条件: 顶格处罚/移送公安立案/全额判赔  │
                       后果: 吊销资质、高管追责、巨额连带赔偿
```

### 步骤 3：黄金应对行动排期 (Contingency Action Plan)
按紧急程度制定时间表：
- **黄金 24 小时（止损与保全）：** 成立危机应急小组；对涉案电子数据、合同凭证进行物理镜像备份与证据固定；冻结内部涉嫌违规操作；
- **关键 72 小时（调查与对接）：** 聘请专业外部律师；开展内部穿透式合规调查；如期提交《听证申请书》或《陈述申辩意见书》；与核心受影响当事人/客户建立沟通热线；
- **后续 7 天（抗辩与和解）：** 出具正式法律意见书；梳理并提交法定从轻/减轻情节证据清单；启动行政复议或和解谈判程序。

### 步骤 4：危机沟通口径与发函策略
1. **事实基准统一：** 所有对外公开发言、内部员工通报及向监管汇报的口径必须严格一致；
2. **严防“法律自认”：** 对外声明中严禁使用“我们承认错误”、“本公司确有违法行为”等自认用语，转为使用“我们高度重视，已第一时间开展内部核查并积极配合监管调查”；
3. **避免次生诽谤与商业诋毁：** 在应对竞争对手挑起的诉讼与公关战时，禁止未经法律核实直接对相对方进行人身攻击。

## 三、四大高频涉法危机场景 Checklist

### 1. 市场监管与不正当竞争调查危机
- [ ] 执法人员是否出示执法证件并送达《立案通知书》/《询问通知书》？
- [ ] 查封、扣押财物或调取电子数据是否开具《财物清单》并由双方签字？
- [ ] 涉嫌违法行为的营业额、违法所得如何计算？是否存在法定从轻情节（如涉案金额较小、主动下架、消除不良影响）？
- [ ] 是否在收到《行政处罚事先告知书》后 5 日内依法申请听证？

### 2. 税务稽查与偷漏税补税危机
- [ ] 稽查局认定的性质是“补缴税款及滞纳金”还是“定性偷税/虚开发票”？
- [ ] 是否满足《刑法》第201条第4款逃税罪“补缴税款、滞纳金、已受行政处罚的不予追究刑事责任”阻却要件？
- [ ] 涉及善意取得虚开增值税专用发票的，是否有真实的交易合同、入库单、银行对公付款凭证支撑？

### 3. 数据安全与个人信息泄露突发危机
- [ ] 泄露数据的范围与敏感程度（是否包含人脸、身份证号、银行卡号、医疗健康信息）？受影响用户数量是否超 10 万人？
- [ ] 是否在 2 小时内向网信及行业主管监管部门进行安全事件初报？
- [ ] 系统漏洞是否已完成技术封堵？访问日志、入侵痕迹是否完成电子取证与固化？
- [ ] 面向受影响用户的告知函是否包含“泄露类型、危害防范建议、补救措施与联系方式”？

### 4. 高管涉嫌职务犯罪/行刑交叉危机
- [ ] 涉案罪名性质（职务侵占、挪用资金、非国家工作人员受贿、商业贿赂）？
- [ ] 涉案行为属于“个人行为”还是“单位行贿/单位犯罪”？单位制度是否明确禁止该类行为？
- [ ] 是否已向办案机关申请律师会见以了解涉案阶段与核心指控？
- [ ] 公司治理与银行印鉴、章证照是否已完成应急接管，防止企业运营瘫痪？

## 三、黄金应急行动排期表 (Action Roadmap)

### 🚨 黄金 24 小时（紧急止损与证据封存）
1. **成立应急指挥小组：** 由法务总监、公关负责人、业务负责人组成，指定对外唯一发声人；
2. **证据镜像保全：** 对涉案服务器日志、业务往来邮件、合规审批记录进行哈希校验并固化保全；
3. **暂停争议行为：** 立即在全渠道下架涉嫌争议的宣传物料，阻断违法状态持续。

### ⏱️ 关键 72 小时（调查与程序权利行使）
4. **提交正式听证申请：** 于期限届满前派专人向市监局递交书面《听证申请书》并取得签收回执；
5. **梳理从轻减轻证据链：** 汇总“已采取补救措施、未造成重大社会危害、积极配合调查”的证明材料；
6. **对接核心合作方：** 向关键投资人与客户出具保密沟通函，澄清案情实际范围，防止恐慌撤资。

### 📅 后续 7 天（听证抗辩与和解跟进）
7. **出具正式代理意见：** 委托执业律师参加听证会，围绕“认定事实不清、裁量畸重”展开对抗；
8. **启动行政和解/整改评估：** 邀请第三方合规专家出具《合规整改报告》，争取中止调查或减轻处罚。

## 五、致命错误防范清单 (Fatal Errors)

| 编号 | 错误类型 | 错误描述与典型表现 | 严重程度 | 防范与纠正措施 |
| :---: | :--- | :--- | :---: | :--- |
| **E01** | 盲目自认认责 | 危机发生后为平息舆论，在公开声明中直接承认“本公司存在违法/侵权行为” | ⭐⭐⭐⭐⭐ 致命 | 声明必须经律师审核，统一表述为“高度重视并开展内部自查”，严禁法理自认 |
| **E02** | 销毁转移证据 | 在执法检查前指使员工删除聊天记录、销毁账册，构成妨害作证或毁灭证据罪 | ⭐⭐⭐⭐⭐ 致命 | 严禁任何销毁证据行为，立即对全量数据进行合法镜像封存并规范保管 |
| **E03** | 逾期放弃程序权利 | 忽视听证申请期限（5日），导致无条件丧失听证质证机会 | ⭐⭐⭐⭐⭐ 致命 | 建立收到公文当日起算的时间警戒线，务必于法定期限内完成书面送达 |
| **E04** | 谎报隐瞒瞒报 | 在数据安全等突发事件中故意隐瞒不报，超过 2 小时未向网信部门报告 | ⭐⭐⭐⭐ 重大 | 严格对照法规法定报告时限，即使事实尚未完全查清亦应先行提交初报 |
| **E05** | 单一情景侥幸心理 | 仅按最乐观情景准备应对，未对悲观情景（顶格处罚、资金链断裂）预留应急现金与处置预案 | ⭐⭐⭐⭐ 重大 | 必须同时推演悲观情景下的备用资金、保全置换担保及业务分流方案 |
| **E06** | 跨部门信息打架 | 向监管汇报的内容与向媒体公布的口径矛盾，被监管认定为态度不端加重处罚 | ⭐⭐⭐⭐ 重大 | 设立唯一的危机新闻发言人与法务审核闸门，所有文字口径完全闭环统一 |

## 六、完整案例演练 (Few-Shot Example)

### 输入（某科技企业突发涉法危机简报）
> “我们是一家做汽车后市场大数据分析的创业公司。今天上午市场监管局执法人员突然上门，出示了立案通知书，称某头部车企举报我们‘利用爬虫技术非法抓取并商业化使用其车主数据，涉嫌不正当竞争’，执法人员现场提取了我们两台服务器镜像，并当场下达了《询问通知书》，要求法定代表人后天上午到局里接受询问。另外，车企同时在法院对我们提起侵权诉讼并申请了诉前财产保全，我们公司的基本户 800 万资金刚刚全被冻结了，员工下周就要发工资，怎么办？”

### 执行推演过程
1. **危机定性：** 行政调查（反不正当竞争法第12条互联网不正当竞争）+ 民事诉讼侵权及诉前保全 + 企业流动性危机。
2. **时间窗口：** 后天上午询问（接受调查）；收到保全裁定 5 日内可提出保全异议或申请置换担保。
3. **多情景推演：**
   - 乐观：爬取数据属于公开数据且未破坏技术防范措施，市监局撤案，民事诉讼和解；
   - 基准：认定构成不正当竞争，处罚 20-50 万元；民事诉讼判赔 100-200 万元；置换担保解冻账户；
   - 悲观：涉及非法获取公民个人信息罪移送公安；顶格处罚 300 万元；账户长期冻结导致破产。

## 三、黄金 24h/72h 应急行动清单
1. **第 1~24 小时（技术阻断与资金抢救）：**

   - 财务与律师立即准备《财产保全异议申请书》及《财产置换保函申请》，向法院申请解冻基本户以发放员工工资与纳税。
2. **第 25~48 小时（询问辅导与口径统一）：**
   - 外部律师进场，对法定代表人及技术主管进行询问前法律辅导，明确“如实陈述客观事实、不确定事项不盲目猜测、拒绝承认主观窃取意图”；

## 七、能力边界与排障指南

1. **不可替代现场律师会见与刑事辩护：** 本技能仅负责输出分析推演与预案框架。涉及刑事人身强制措施（拘留、逮捕）或重大庭审辩护，必须由具备刑事辩护资格的执业律师实地办理。
2. **动态推演原则：** 危机应对过程中一旦出现重大新事实（如监管机关追加违法认定、相对方扩大索赔金额），必须立即重新执行本技能更新决策树与行动排期。
