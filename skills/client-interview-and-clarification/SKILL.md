# 客户沟通与事实澄清发问

## 概述表格
| 项目 | 内容 |
|------|------|
| **能力名称** | 客户沟通与事实澄清发问 (Client Interview & Fact Clarification) |
| **核心目标** | 识别案情陈述中的要件事实缺口，生成通俗易懂、具有引导性的澄清发问清单与证据收集指引 |
| **输入** | 当事人口述事实、咨询记录、微信沟通摘要、业务往来邮件等非结构化文本 |
| **输出** | ① 已确认事实与缺口事实矩阵；② 面向当事人的通俗澄清问卷（含选项与示例）；③ 证据调取与补强线索指引 |
| **前置技能** | 无（作为法律分析流程的第一道事实获取闸门） |
| **后续技能** | `legal-element-extraction`（要素提取）、`dispute-issue-identification`（争点识别）、`evidence-evaluation`（证据评估） |
| **风险等级** | **中高** — 遗漏关键要件事实将直接导致下游三段论推理大前提错位或抗辩漏洞 |
| **适用法域** | 中华人民共和国成文法体系（民商事、劳动争议、行政及刑事初核） |

## 法律声明
> **重要提示：** 本技能仅供辅助法律专业人员或智能体系统进行事实梳理、要件补全与沟通提问设计，不构成正式的律师当面会见笔录或委托代理意见。AI 智能体在执行本技能时应当：
> 1. 采用温和、客观、中立的语气，严禁进行诱导性发问（Leading Questions）以防诱发伪证；
> 2. 向当事人明确提示所提问题仅为厘清事实逻辑，不代表对案件胜诉率或法律责任的预先承诺；
> 3. 涉及重大时效利益（如除斥期间届满前夕）时，明确提示当事人尽快寻求执业律师面谈以采取保全或诉讼中断措施。

## 一、理论依据与认知模型

法律事实的获取并非被动的信息接收，而是一个由规范反向指引事实的互动建构过程：

1. **请求权基础分析法 (Anspruchsgrundlage)：** “谁得向谁，依据何种规范，主张何种权利？”——法律要件决定了事实的调查边界，缺乏要件支撑的事实为无效噪音，缺乏事实支撑的要件为致命漏洞。
2. **认知访谈理论 (Cognitive Interviewing)：** 当事人常受情绪干扰与记忆衰退影响，通过“时间线倒叙/正叙重构”、“场景情境恢复”和“多角度提示”可有效激活沉睡的关键细节。
3. **信息不对称与沟通转化理论：** 严禁使用纯法言法语向非专业当事人提问，必须将“法定构成要件”转译为“生活经验语言与客观行为描述”。

## 二、标准执行工作流程

### 步骤 1：事实要素初筛与请求权初步映射
1. **剥离情绪与主观评价：** 过滤当事人叙述中的辱骂、主观臆测、价值判断词汇（如“对方是个大骗子”、“他存心坑我”），提取客观发生的行为、时间、主体、交付及金额。
2. **初步定性法律关系：** 识别潜在的案由方向（如民间借贷、买卖合同违约、劳动用工解除、机动车侵权责任等）。
3. **建立初始时间轴：** 按照时间顺序对已知事件进行编排，标记时间断层节点。

### 步骤 2：法律构成要件与证据缺口扫描
对照所涉案由的核心法定要件，执行“有/无/存疑”的三色筛查：
- **🟢 已具备事实 (Confirmed Facts)：** 双方主体明确、金额确定、已有书面协议等。
- **🟡 模糊/存疑事实 (Vague Facts)：** 提到了某种行为但缺乏具体时间、地点、履行方式或交付凭证。
- **🔴 致命缺口事实 (Critical Missing Elements)：** 决定请求权能否成立的关键要件完全未提及（例如：买卖合同未提及是否在检验期内提出异议；民间借贷未提及款项是以现金还是转账交付；侵权纠纷未提及受害人自身是否存在过错）。

### 步骤 3：三级澄清发问与沟通话术生成
针对扫描出的缺口，按照重要性梯队生成面向客户的结构化问卷：

```
Level 1：核心要件必查追问（生死线）
  └─ 决定请求权能否成立、合同是否生效、行为是否违法的基础事实。
  
Level 2：补强证据与线索追问（证明力）
  └─ 引导当事人去何处调取书证、电子数据、第三方凭证（微信记录、银行流水、邮件记录）。
  
Level 3：对方潜在抗辩与防御性追问（防守面）
  └─ 预先排查对方可能提出的抗辩事由（时效届满、先履行抗辩、不可抗力、当事人过错等）。
```

**提问转译原则：**
- ❌ **严禁提问：** “请问本案是否存在诉讼时效中断的事由？”
- ✅ **推荐提问：** “在对方承诺还款的日期之后，您在这 3 年里有没有通过微信、短信、电话或发函向他催过款？对方是怎么回复的？”

### 步骤 4：动态事实闭环与下游衔接
当事人做出答复后，将新增事实补充进事实矩阵：
- 若所有 Level 1 核心要件均已补齐且证据线索清晰，生成《案件完备事实摘要》，流向 `legal-element-extraction` 或 `dispute-issue-identification`；
- 若仍存在关键缺口或当事人明确表示“无法提供证据/确实未曾约定”，标注为 **[确定性缺失事实]**，并在后续法律分析中提示“该主张因举证不能面临败诉风险”。

## 三、五大高频实务案由澄清清单

### 1. 民间借贷纠纷
- [ ] **借贷合意：** 是否有借条、借据、借款合同、还款承诺书？若无书面字据，微信/短信聊天中是否有借款金额、利息、还款期限的明确沟通？
- [ ] **款项实际交付（实践性合同关键）：** 钱是通过银行转账、微信/支付宝还是现金交付？转账流水备注是什么？现金交付是否有收条或取款凭证？
- [ ] **还款与付息记录：** 对方是否还过部分本金或利息？是通过什么方式归还的？双方核对过剩余欠款账目吗？
- [ ] **保证与担保：** 是否有保证人签字？保证方式是连带责任还是一般保证？有无提供抵押物并办理登记？
- [ ] **诉讼时效：** 约定的还款期限是哪一天？到期后是否有持续催款记录（催款微信、通话录音、律师函）？

### 2. 买卖合同纠纷（货款/质量争议）
- [ ] **合同成立与订单：** 有无订立正式合同？采购单、对账单、微信确认单是否有对方签字或盖章？盖章主体是否为签约当事人？
- [ ] **发货与签收凭证：** 货物如何交付？是否有送货单、物流运单、签收单？签收人是否为对方员工或有授权委托书？
- [ ] **质量异议与检验期间：** 对方收到货后多长时间内提出的异议？是通过电话口头还是书面/微信提出的？是否在合同约定的检验期内？
- [ ] **退货与折价协商：** 双方是否就瑕疵货物达成过换货、折价赔偿或退款协议？

### 3. 劳动争议（解除劳动关系/薪酬纠纷）
- [ ] **用工关系建立：** 入职时间是哪一天？劳动合同签订了吗？未签合同的实际工作期间是多久？
- [ ] **工资构成与发放：** 约定月薪是多少（基本工资+绩效+提成）？工资发放日是哪天？每月工资条、银行代发流水是否有保留？
- [ ] **解除劳动关系的形式：** 是用人单位口头辞退、发送《辞退通知书》、停缴社保，还是劳动者主动辞职？通知书上写明的解除理由是什么？
- [ ] **考勤与加班：** 是否存在加班？打卡记录、加班审批单、工作群加班沟通记录是否保存？
- [ ] **仲裁时效节点：** 离职日期（最后工作日）是哪一天？

### 4. 机动车交通事故责任纠纷
- [ ] **事故定责：** 是否报警？交警部门是否出具《道路交通事故认定书》？双方各承担何种责任比例？
- [ ] **保险覆盖情况：** 肇事车辆投保了哪家保险公司的交强险和商业三者险？保额各是多少？是否在保险期内？
- [ ] **人身损害与医疗凭证：** 是否住院治疗？医药费发票、用药明细、病历、出院小结、医疗费垫付情况如何？
- [ ] **伤残与误工：** 是否已做伤残等级鉴定？伤者的职业证明、收入证明及误工休假证明是否齐备？

### 5. 房屋租赁合同纠纷
- [ ] **租赁标的与合同：** 租赁房屋坐落地址？租赁期限起止日？租金标准及支付周期（押几付几）？
- [ ] **交房与押金：** 是否办理了房屋交接清单？押金收据或转账凭证是否保留？
- [ ] **违约与转租：** 违约行为是什么（拖欠租金、擅自转租、损坏房屋、提前退租）？发生违约后是否发送过催告函或解除合同通知？
- [ ] **腾房与现状：** 房屋目前由谁占有？是否已实际腾空移交钥匙？

## 二、面向客户的通俗澄清问卷（供直接复制发送给当事人）
> 💡 *提示：为了帮您准确评估案件法律依据并制定维权方案，请您根据实际情况补充以下几个关键细节：*

### 🔴 核心事实确认（关乎案件能否立案与胜诉）
1. **关于款项实际交付方式：**
   - [ ] 请问这笔 20 万元中，有多少是通过微信/支付宝/银行转账的？有多少是直接给的现金？
   - [ ] （若是现金交付）给现金时现场是否有其他人在场？对方事后有没有发微信确认“钱收到了”？
2. **关于还款期限与利息：**
   - [ ] 当时双方有没有约定什么时候还钱？是口头约定还是微信里聊过？
   - [ ] 借款期间对方是否曾还过部分款项（无论是本金还是利息）？

### 🟡 证据调取与线索补充
3. **关于微信聊天记录与转账凭证：**
   - [ ] 您能找到当时的微信转账电子回单吗？（可在微信：我→服务→钱包→账单→点击对应转账→申请转账电子凭证）
   - [ ] 您和对方近 3 年关于这笔款项的微信聊天记录是否还在手机里完整保存？

### 🔵 防御性问题（预判对方可能找的借口）
4. **关于双方是否存在其他经济往来：**
   - [ ] 对方收到这笔钱，会不会辩称是双方合伙做生意的投资款、或者之前的货款往来？你们之间还有没有其他未结清的账目？

## 三、证据收集与维权行动建议
- **紧急动作：** 立即在微信/支付宝导出官方《转账电子凭证》并保全原始聊天记录；
- **补强方案：** 若现金部分无直接凭证，建议近期通过微信向对方发送对账信息（如：“兄弟，之前 2021 年 5 月转你 12 万，另外在茶楼给你的 8 万现金，总共 20 万现在周转困难，能否先还一部分？”），引导对方在回复中确认收到现金的事实。

## 五、致命错误防范清单 (Fatal Errors)

| 编号 | 错误类型 | 错误描述与典型表现 | 严重程度 | 防范与纠正措施 |
| :---: | :--- | :--- | :---: | :--- |
| **E01** | 法言法语轰炸 | 使用“抗辩权”、“要约承诺”、“给付迟延”、“除斥期间”等生涩术语向当事人提问，造成沟通障碍 | ⭐⭐⭐⭐ 重大 | 严格执行生活化转译，用客观行为与选择题形式引导 |
| **E02** | 诱导性发问 | 提示“您当时是不是受到了欺诈才签字的？”，诱导当事人编造不实事实 | ⭐⭐⭐⭐⭐ 致命 | 采用中立开放式提问：“您当时是在什么情况下签署这份协议的？” |
| **E03** | 遗漏交付要件 | 在实践合同（民间借贷、保管等）中仅核实字据，漏查款项/标的物实际交付凭证 | ⭐⭐⭐⭐⭐ 致命 | 强制将“交付方式与流水凭证”设为民间借贷案由的第一优先级必查项 |
| **E04** | 忽视时效断层 | 仅关注案发当时事实，未询问后续催告与时效中断记录，导致进入诉讼后遭遇时效抗辩败诉 | ⭐⭐⭐⭐ 重大 | 只要纠纷发生超 2 年，必须强制扫描最近 3 年内的催讨、对账、承诺证据 |
| **E05** | 忽略对方抗辩 | 只听取己方有利于自己的陈述，未主动追问对方可能持有的反驳事实与抗辩理由 | ⭐⭐⭐⭐ 重大 | 设置 Level 3 必问环节，审查是否存在基础法律关系瑕疵或反向违约 |
| **E06** | 虚假承诺预期 | 在事实尚未澄清完备前向当事人承诺“这案子一定能赢”或“肯定能全额赔偿” | ⭐⭐⭐⭐⭐ 致命 | 严格遵守法律声明，明确提示输出为事实整理草稿，诉讼存在举证风险 |

## 六、完整案例演练 (Few-Shot Example)

### 输入（当事人原始口语咨询）
> “我去年6月卖给张三一批建筑钢材，总共值35万。货送过去了，张三一直拖着不给钱，每次找他就说工地没结款。上个月我听说他把公司营业执照注销了人也找不到了！我手里只有当初一张他签了字的送货单，我现在该怎么把钱要回来啊？”

### 执行过程
1. **识别请求权基础：** 买卖合同货款给付请求权（《民法典》第595条、第626条）+ 公司注销后股东清算责任追索（《公司法》）。
2. **扫描事实缺口：**
   - 主体层面：签约主体是张三个人还是张三的公司？若是公司，注销时清算报告是如何处理该笔债务的？股东是谁？
   - 履约层面：送货单上是否有具体单价、数量、总金额？张三签字是以个人身份还是法定代表人/职务代理人？
   - 异议层面：送货后张三对钢材规格、质量是否有过异议？双方是否签署过最终结算对账单？

## 七、能力边界与排障指南

1. **不可替代正式会见调查：** 本技能输出的发问清单用于高效筛查事实，涉及当事人可能承担刑事责任（如涉嫌虚假诉讼、合同诈骗）或重大财产处分的案件，必须由专业执业律师进行线下面对面笔录调查。
2. **当事人拒绝或无法回答时的降级处理：** 若当事人表示关键证据已遗失且无法补充，智能体应在下游分析中立即切换为“举证责任分配与败诉风险评估”视角，禁止假设未证实的事实成立。
